ITL WEBSITE — QUICK START

1. Extract the ITL-Website folder.
2. Open index.html in Chrome, Edge or Firefox.
3. For editing, open the folder in VS Code.

FILES
- index.html: page content and sections
- styles.css: colours, layout, responsive design and animations
- script.js: mobile navigation and demo fan-vote interaction

CUSTOMISE
- Replace the sample member names and descriptions in index.html.
- Replace the Discord URL in the JOIN ITL button with your actual invite link.
- Replace the Unsplash image URLs with your own ITL screenshots/photos if desired.
- The vote is a front-end demo only. It does not save votes to a server or database.

The page uses Google Fonts and remote Unsplash images, so an internet connection is needed for those assets. The website itself runs locally without a build step.
